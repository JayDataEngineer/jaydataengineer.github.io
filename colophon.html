How this site is built.

The site is itself a portfolio piece. Every choice is deliberate and the rationale is in the source.

//Stack
Framework
Next.js 16 (App Router, Turbopack, RSC)
Language
TypeScript, strict
Styling
Tailwind CSS v4 — CSS-first config
3D
Three.js via React Three Fiber + custom GLSL
Motion
Motion (formerly Framer Motion)
Content
MDX with gray-matter frontmatter
Live data
GitHub REST at build time → committed snapshot
Type
Geist Sans + Geist Mono (variable)
Icons
Lucide
Package manager
pnpm
Deploy
GitHub Pages via Actions — push to main
//Principles
  • →Dark only. No toggle. The aesthetic is the brand.
  • →No motion without purpose. Decoration gets cut.
  • →Respect prefers-reduced-motion everywhere.
  • →Single-page scroll for the core narrative; project detail pages only for marquee work.
  • →Source READMEs as ground truth — link, don't paraphrase.
  • →Lighthouse 95 mobile / 100 desktop — measured, not aspirational.

$ open source
