Melite

An agent media-creation kit — agents compose cards on a shared bench, the estate validates one run at a time against ComfyUI.

TypeScriptCordisComfyUIDSH
GitHub

Melite is a DSH-seated agent kit for media creation: users and agents compose cards on a shared bench, the estate validates each card, queues one run at a time, calls ComfyUI behind an engines contract, and serves the artifacts. Installed the DSH way — dsh plugin --profile melite add "github:JayDataEngineer/melite#v0.2.2-alpha" — pinned releases, never a moving tip. AGPL-3.0-or-later.

//Three layers, one contract

LayerWhat it is
A — Cordis harnessTool surface, shared bench, card view + deck, run registry, Typert remotes, operator studio. Seventy-two bench tools; Cordis is the sole framework.
B — enginesComfyUI and MCP-backed engines behind the engines service contract. Layer A calls; it never modifies an engine.
C — engine extensionsFirst-party and forked ComfyUI packs, vendored as pinned git submodules with upstream attribution.

Agents compose through progressive disclosure — melite_discover finds the card or flow, melite_load opens its params/models/skills, melite_construct authors the bench with add_stage / patch / rewire. The user watches the bench build live in the Cards tab and presses Run. Hand-rolling a workflow or curling ComfyUI is a contract violation, not a shortcut.

Acquiring a missing model is a first-class path, not a shell script: the agent goes through comfy_manage (install_extension, provision_model, acquire_weight), and every downloaded file is verified against its declared sha256 — the digest gate owns the download boundary.

//The packs

Twelve domain slices partition the estate (harness, engines, image, video, audio, motion, 3d, models, estate, web, web-kit, vendor), and four named flows ship ready to run: character-factory, craft-loop, image-upscale, object-forge.

The character lane is the deep end. melite-kimodo-nodes wraps NVIDIA's kimodo package (KimodoLoader, KimodoTextToPose — text to motion) and adds the Anny parametric-human lane: multi-person image→params regression with VRAM tracking, camera-space fit optimization, and graph-side grounding — engineered as a license-clean dual path around NAVER's non-commercial upstreams. melite-poser-nodes is the template-mesh pipeline around it: bind, deform, render depth/RGB/OpenPose, project views back to texture, and SAM-segment hair and clothing. melite-audio-nodes fronts a forked C++ audio engine — TTS, music, voice embedding, voice studio — with the pinned native library fetched and sha-verified at install time. On the video lane, the MiniMax-H3 lane is first-party where it matters — motion-cache FastVAE and timeline-director are mine — and honest where it is not: context-loop tracks ethanfel's GPL-3.0 pack and MiniMaxH3Mod forks Luisacaotica's MIT one, pinned and attributed.

//What got removed

Blender. An operator ruling pulled it out of the estate entirely — no node, no server, no subprocess; Blender and Unity ride separate DSH profiles (mega-blender, mega-unity, game). The removal is enforced by a wall test (blender-lane-removal.spec.ts) that goes red if any blender seat reappears. Scope discipline is a feature: four tools against a bench that size didn't earn their maintenance.

//How it's held together

Vitest unit, real-API e2e, performance benchmarks, keyless recorded-session replay, and web snapshots — with a per-file coverage gate on the gated source and an arch-lint that keeps the layers honest. Model weights keep their upstream licenses; the NOTICE file draws the line between AGPL code and provisioned artifacts.
