// current focus

  • → Distributed systems for generative AI
  • → Ray Serve + KubeRay on consumer GPUs
  • → MCP servers as a first-class integration surface
  • → Declarative config over bespoke orchestration code
  • → Sandbox isolation, proved adversarially
  • → Self-hosted everything — k3s, Caddy, Tailscale

I'm Jay, an AI infrastructure engineer. My home lab runs a Ray Serve cluster on k3s that generates images, video, audio, 3D, and text through one unified API. I built the agent platform that drives it — and rewrote it five times, deleting my own Go kernel when it stopped earning its keep. I tune TTS models with LoRA for emotion-controlled character voices. I ship the MCP servers that let agents reach into the cluster.

Generation is the easy part. The work is everything around it — VRAM scheduling, request routing, sandbox isolation, observability, and the seams between agents and tools. A demo either grows into infrastructure or it was never real. I build the part that grows.
